# PLAN.md — lantip.space website (v1)

*The working plan for this repo (`website-3`). Supersedes the earlier `plan.md` in the parent
directory for everything website-related. Parent `plan.md` remains the strategy document for
data/model/tools; this file is only about the site.*

---

## 1. What this is

The static home of lantip.space: a quiet catalogue of three shelves —

1. **tools** — LantipScript (shipped, v1.0.0), Cartouche (in progress)
2. **models** — Lantev (in progress, no endpoint yet)
3. **data** — frozen ASEAN geodata, Hugging Face hosted (first sheet not yet published)

The site is where people **download the tools** and **find the endpoints** for models and data.
Nothing else. No waitlists, no newsletters, no hype.

## 3. Theme — "the plate"

Banknote/atlas-plate register: paper + navy ink + one terracotta accent. The engraving is the
paper, not the poster. Ornaments live only in headers, plate corners, stamps, and dividers —
never behind body text. Every artifact is presented as a numbered **plate** with edition,
as-of date, and format rows, so the banknote language does real work.

### Design tokens

| Token | Value | Use |
|---|---|---|
| `--color-paper` | `#f5f0e6` | page background |
| `--color-paper-deep` | `#ece4d4` | wells, table stripes |
| `--color-ink` | `#1d3a5c` | body text |
| `--color-ink-deep` | `#142c47` | headings, strong |
| `--color-ink-soft` | `#4a6486` | secondary text |
| `--color-rule` | `rgba(29,58,92,.18)` | hairlines |
| `--color-accent` | `#a8451f` | links, small text (contrast-safe) |
| `--color-accent-bright` | `#c05a33` | fills, stamps, large display only |

Type: EB Garamond for everything; uppercase + letterspaced for stamps/labels; Fragment Mono
for endpoints, versions, checksums, filenames.

### Ornaments (procedural)

Generated by `tools/guilloche.mjs` (own implementation of standard spirograph / radial-wave /
linear-wave math; inspired by the open-source guilloche generators listed in
`SOURCES.md` — none of their code is vendored). Output committed to `src/ornaments/` and
inlined via `?raw` imports, so each SVG inherits `currentColor`:

- `header-band.svg` — wide epicycloid band, sits under the header
- `rosette.svg` — banknote rosette; used as a watermark (home hero, 404, cartouche)
- `divider.svg` — small horizontal wave for section rules
- paper grain is a CSS data-URI (SVG turbulence) in `global.css`, no file needed

## 4. Artwork — public-domain engravings

Historical Indonesian archipelago engravings from Wikimedia Commons (PD-old) and Rijksmuseum
(public domain), verified per file via the Commons API. Provenance, license, and processing
notes in [`SOURCES.md`](SOURCES.md). Processed by `tools/plates.py` into navy duotone WebP.

Rule: no banknote scans (currency reproduction law varies by jurisdiction), no AI-drawn
reconstructions of engravings.

## 6. Voice

From parent `plan.md` §3.4, non-negotiable:

- Concrete numbers over adjectives ("64-d int8, 10 m" not "high-resolution").
- One honest limitation per page, attached to a fact.
- Ban list: revolutionize, empower, seamless, unlock, cutting-edge, AI-powered, "we believe",
  "our mission", exclamation marks in copy.
- Dry, not zany. Humour is in precision.
- Never compare yourself to a company.

## 7. Budgets & quality bars

- JS shipped: < 15 KB (only copy-to-clipboard).
- Page weight: < 500 KB above the fold, images < 300 KB each.
- Ornament SVGs: < 15 KB each after optimization.
- Contrast: body ink on paper ≥ 7:1; accent text ≥ 4.5:1 (hence `#a8451f`, not `#c05a33`).
- `prefers-reduced-motion` respected; zero motion by default anyway.
- Lighthouse: 95+ across the board.
