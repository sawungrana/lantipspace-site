## TL;DR

- This repo is the static site for **lantip.space**, built with **Astro + Tailwind v4**.
- Content pages are plain `.astro` files in `src/pages/`; shared pieces in `src/components/`.
- Ornaments and plates are generated by scripts in `tools/` and committed. Nothing is fetched
  at build time except npm deps.
- Deploy target: **Cloudflare Pages** (not yet connected — steps below).
- Repo: [sawungrana/lantipspace-site](https://github.com/sawungrana/lantipspace-site) (branch `main`).
- Read `PLAN.md` before changing anything. Read `LOG.md` for what happened.

## Local development

```sh
npm install
npm run dev        # or: astro dev --background   (see AGENTS.md)
npm run build      # static output in dist/
npm run preview
```

## Deploy (Cloudflare Pages)

1. Push to GitHub (repo: `sawungrana/lantipspace-site`).
2. Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git → pick the repo.
3. Build settings: framework `Astro`, build command `npm run build`, output `dist`.
4. After first successful deploy: add custom domain `lantip.space` (and `www` if wanted) in
   Pages → Custom domains. Cloudflare manages DNS since the zone is already on Cloudflare.
5. Verify the old beta-funnel site is replaced; archive `sawungrana/lantipspace-website`.

## Updating content

- **Lantipscript release links:** the site links **direct release assets** (live since
  v1.0.0, 2026-10-16). Filename pattern:
  `lantipscript_{full|lite|express}_{mac|windows}_<version>_{aarch64|x64}.{dmg|exe}`;
  macOS builds are Apple silicon only. On the next release, update the six hrefs + sizes in
  `src/pages/lantipscript.astro` and the tier map in `src/pages/catalog.json.ts` (asset
  sizes: `gh api repos/sawungrana/lantipscript/releases/tags/<tag>`; the table shows MiB,
  rounded). The releases page stays linked as the fallback.
- **First dataset published:** add its entry to `src/pages/catalog.json.ts`, turn the
  `/data` empty state into a real shelf, and mirror the HF README (write once, publish
  twice — see parent `plan.md`).
- **Lantev endpoint live:** update `/lantev` and `catalog.json`; remove the "no endpoint
  yet" line.

## Rules that keep this from rotting

- Only link to files that exist *right now*. `/data` never becomes a promise list.
- One honest limitation per page, attached to a fact. Ban list in `PLAN.md` §6.
- If maintaining the site takes more than an hour a month, cut something.
